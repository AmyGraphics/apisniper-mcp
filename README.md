# APISniper MCP Server 📡⚡🎯

Universal Reverse API, cURL to TypeScript SDK, Zod Schema & Network Inspector MCP Server for **Cursor, Claude Code, and Windsurf**.

## 🌟 Core Capabilities:
- 🎯 **cURL to Typed Client SDK:** Convert raw cURL into TypeScript (Fetch / Axios) or Python (Requests / HTTPX) clients with types.
- 🛡️ **JSON to Zod / Pydantic Schema:** Synthesize production-ready Zod & Pydantic validation schemas with inferred types.
- 🔍 **Live Domain & DNS Inspector:** Live DNS records (A, MX, NS), SSL checks, HTTP security headers (HSTS, CSP, CORS), and latency benchmarking.
- 🧪 **Mock API Generator:** Next.js App Router & Express mock route handlers with dynamic filtering.
